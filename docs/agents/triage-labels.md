# Triage Labels

Five canonical triage roles, and the label strings that carry them in this repository's
issue tracker. Where a process refers to a role, use the label string from the right-hand
column.

| Role              | Label in this tracker | Meaning                                  |
| ----------------- | --------------------- | ---------------------------------------- |
| `needs-triage`    | `needs-triage`        | Needs evaluating before anyone starts     |
| `needs-info`      | `needs-info`          | Waiting on the reporter for more detail   |
| `ready-for-agent` | `ready-for-agent`     | Fully specified and ready to be picked up unattended |
| `ready-for-human` | `ready-for-human`     | Requires a person                         |
| `wontfix`         | `wontfix`             | Will not be actioned                      |

The labels themselves are maintained on GitHub and must exist there for issue routing to
work. If a label in this table is missing from the repository, restore it rather than
renaming the role.
